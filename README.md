■サービス概要
ユーザーが購入したい商品や貯金など、自分が達成したい目標を記載(投稿方法は、手書き風の自由入力フォームで記載してもらいます)する。
外部のユーザーがそれを応援(♡でいいねやコメント)する事ができる仕組みです。

■ このサービスへの思い・作りたい理由
このサービスの思いは、自分が初めてノートPCを購入しようとした時、そのPCが10万円したのでコツコツ貯金をして購入した経験や社会人になって初めて貯金が100万を超えた時など、苦労をして達成したことがあるので、達成感をユーザーに体験してもらうために作りました。また、私の場合、一人で苦労をしていため結構つらい思いをしたけど、ユーチューブの動画などで同じような思いをしている人を見て自分だけではないと知り頑張る事が出来たのでそのような場所を提供したいと考えています。

■ ユーザー層について
一人では達成困難な人をターゲットにしている。(意志薄弱な人)

■サービスの利用イメージ
webページを利用して、ユーザーが設定した目標に向けて、進捗を記載して別のユーザーが♡でいいねやアドバイスなどをもらい目標に向けてモチベーションを高め目標を達成して達成感を感じてもらうことです。また、ユーザーが投稿した内容は、公開や非公開にすることによって、他のユーザーと比較することなく自分のペースで目標まで到達することができます。
また、初期段階ではユーザー数が少ないため、自然な応援が発生しにくいという問題があります。この問題については、運営者である私が、積極的に♡でいいねやコメントを送ることで、ユーザー同士のコミュニケーションを促進する予定です。

円グラフに表示するために下記のユーザー情報が必要になります。
目標値: 最終的に達成したい数値（例：100,000円など）
現在の進捗: 現時点での達成数値（例：30,000円など）
更新日時: 進捗が更新された日時（進捗の推移を把握するため）
更新頻度: 進捗を更新する間隔（例：毎日、毎週など）

円グラフの数値を表示させるための計算式が下記になります。
進捗率（現在の進捗 ÷ 目標値 × 100）

数値で判断できないような目標の場合、例えば4か月でエンジニアになりたいなど。
上記の場合、数値で表現できない目標については、達成すべき各ステップを明確に設定し、各ステップが完了するたびに進捗率を更新する仕組みを導入します。
1か月、2か月、3か月、4か月のようにそれぞれのステップを明確にして、1つ達成すれば、25％進捗率が上がるようにする。

目標達成についてですが、現在の仕様＋リマインダー機能を追加することで、最後まで挫折やサボることを防止する役割を作成してユーザーのサポートしたいと考えている。

■ サービスの差別化ポイント・推しポイント
似たようなサービスが存在する場合、そのサービスとの明確な差別化ポイントとその差別化ポイントのどこが優れているのか教えてください。
独自性の強いサービスの場合、このサービスの推しとなるポイントを教えてください。

差別化のポイントですが、chatGPTで調べた限り、下記のようなサービスがあります。
StickK: ユーザーが目標達成のために契約を結び、目標未達成の場合はペナルティが課される仕組み。
Beeminder: ユーザーが目標に対する進捗を記録し、目標が達成できなかった場合にお金が引かれる仕組み（リスクを伴う）。
上記の場合では、失敗した時にペナルティが大きすぎる為、気軽にできないという点があります。一方で、私の作成したいアプリでは、ペナルティがないので気軽に使用することができる点が差別化できているのではないかと思います。また、私自身が調べた限り、多くの目標管理アプリは月額制を採用しているところが多いですが私のアプリでは無料なのでユーザーが気軽に使用できる点が差別化できているところです。

このサービスの推しは、自分の目標を設定してそれを達成する事がこのサービスの推しとなっている。また、SNSに目標を書く人がいるが、それだと他人と比較したりSNSを見ることで余計な情報が入り集中できない。

■ 機能候補
現状作ろうと思っている機能、案段階の機能をしっかりと固まっていなくても構わないのでMVPリリース時に作っていたいもの、本リリースまでに作っていたいものをそれぞれ分けて教えてください。

MVPリリース時に作成したい機能一覧

1.ユーザー登録・ログイン機能
  ユーザー認証（メールアドレス・パスワード）を実装する

2.目標投稿機能
  ユーザーが達成したい目標（購入したい商品、貯金目標など）を、手書き風の自由入力フォームで投稿できる

3.進捗更新機能
  ユーザーが定期的に（毎日・毎週）進捗率（例：現在の達成数値）を記入する
  入力された目標値と現在の進捗から、進捗率＝（現在の進捗 ÷ 目標値 × 100）を算出し、Chartkick Gem＋Chart.js を使用して円グラフで表示

4.応援・コメント機能
  他のユーザーが投稿に対して「♡」やコメントで応援できるシンプルな仕組み

本リリースまでに追加したい機能

1.SNS連携機能
 目標投稿をX（Twitter）でシェアできる機能
 使用するAPI：Twitter API v2
 ユーザーが自ら拡散することで、認知度の拡大を図る

2.通知機能
 進捗更新や応援・コメントがあった際にプッシュ通知で知らせる機能
 使用するAPI：Firebase Cloud Messaging (FCM)

3.バッジシステムの追加
 ユーザーが目標達成に、バッジを付与される仕組み
 モチベーション向上をサポート

4.目標達成後の報告機能
  目標達成後、ユーザーが達成の報告を行い、感謝のメッセージを投稿、他のユーザーから祝福を受ける仕組み

5.数値で表現できない目標の進捗管理
 例：「4か月でエンジニアになる」のような目標は、達成すべき各ステップ（1か月、2か月、3か月、4か月）に分割し、各ステップが完了するごとに進捗率（例：各25%）を            
 更新する仕組みです
