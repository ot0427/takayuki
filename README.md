








このアプリは、ユーザーが自分の達成したい金銭的な目標（例：購入したい商品、貯金目標など）を手書き風の自由入力フォームで記載し、外部のユーザーが「♡」やコメントで応援することで、目標達成までのプロセスを支援するアプリです。初期段階では、具体的な金銭目標を数値で管理できるユーザーを対象に、進捗状況を円グラフで可視化し、達成感を感じてもらう仕組みを提供します。本リリース以降は、ユーザーは、投稿した目標を公開または非公開に設定できるため、他者と比較せず自分のペースで目標に向かうことが可能です。また、運営者が初期段階で積極的に応援メッセージを送ることで、ユーザー同士のコミュニケーションも促進し、継続的なモチベーション維持をサポートします。
