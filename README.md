■サービス概要
ユーザーが購入したい商品や貯金など、自分が行動に移したい事を書く。外部のユーザーがそれを応援する事ができる仕組みです。

■ このサービスへの思い・作りたい理由
このサービスの思いは、自分が初めてノートPCを購入しようとした時、そのPCが10万円したのでコツコツ貯金をして購入した経験や社会人になって初めて貯金が100万と超えた時など、我慢をして達成したことがあるので、達成感をユーザーに体験してもらうために作りました。また、私の場合、一人で我慢をしていため、結構つらい思いをしたので同じような経験をした他のユーザーから応援していただけるようなサービスを作成したいと考えた。

■ ユーザー層について
一人では達成困難な人をターゲットにしている。(意志薄弱な人)

■サービスの利用イメージ
webページで利用でき、ユーザーには、自分の欲しい物を設定してそれを手に入れるため行動を起こして手に入れる事です。

■ ユーザーの獲得について
想定したユーザー層に対してそれぞれどのようにサービスを届けるのか現状考えていることがあれば教えてください。
SNSを用いてユーザーに認知してもらい、サービスを提供する。

■ サービスの差別化ポイント・推しポイント
似たようなサービスが存在する場合、そのサービスとの明確な差別化ポイントとその差別化ポイントのどこが優れているのか教えてください。
独自性の強いサービスの場合、このサービスの推しとなるポイントを教えてください。

A.このサービスの推しは、自分の目標を設定してそれを達成する事がこのサービスの推しとなっている。また、SNSに目標を書く人がいるが、それだと他人と比較したりSNSを見ることで余計な情報が入り集中できない。
